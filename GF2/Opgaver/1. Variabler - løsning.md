# Vejledende løsning: 1. Variabler

Brug denne fil kun hvis du er stødt på problemer. Prøv selv først!

---

## Opgave 2 – double

```csharp
double værdi = 5.25;
Console.WriteLine(værdi);
```

---

## Opgave 3 – string

```csharp
string tekst = "Hello, World!";
Console.WriteLine(tekst);
```

---

## Opgave 4 – bool

```csharp
bool erSandt = true;  // eller false
Console.WriteLine(erSandt);
```

---

## Opgave 5 – string interpolation (to variabler)

```csharp
string del1 = "Hello, ";
string del2 = "World!";
Console.WriteLine($"{del1}{del2}");
```

---

## Opgave 6 – string interpolation (fire dele → "Hej med dig!")

```csharp
Console.WriteLine($"{del1} {del4} {del3}{del2}");
```

---

## Opgave 7 – float

```csharp
float tal = 3.14f;

```

## Opgave 8 – char

## Opgave 9 – decimal
