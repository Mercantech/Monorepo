Visuelt SSO Flow Diagram

Flutter, Google (OpenID) og .NET JWT API

Bruger
Flutter-app
Google (IdP)
.NET API

Trin 1-4: Brugergodkendelse

1
Bruger → Flutter-app: Initierer "Log ind med Google".
2
Flutter-app → Google: Omdirigerer til Google for autorisation.
3
Bruger → Google: Logger ind og giver samtykke.
4
Google → Flutter-app: Returnerer **Google ID Token** via redirect.

Trin 5-9: API Token Udveksling

5
Flutter-app → .NET API: Sender Google ID Token til `/api/auth/google`.
6
.NET API → Google: **Validerer** tokenets signatur (serverside).
7
.NET API: Opretter/opdaterer bruger i egen database.
8
.NET API → Flutter-app: Returnerer **Custom API JWT**.
9
Flutter-app: Gemmer det interne JWT sikkert (secure storage).

Trin 10-11: Normal App-brug

10
Flutter-app → .NET API: Kalder beskyttede endpoints med `Bearer `.
11
.NET API: Validerer det interne JWT og returnerer data.
